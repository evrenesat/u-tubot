# u·tubot browser extension

Firefox first (desktop and Android), Chromium browsers on desktop after it. It talks to the user's own u·tubot server over the
same contract as the TV app. The plan, parity matrix and checkpoints are in `ai/BROWSER_EXTENSION_PLAN.md`.

Development: `AGENTS.md`. Build and test: `docs/development.md`. Install: `docs/install.md`. Privacy: `docs/privacy.md`.
